# Sales Analysis Dashboard (Q1 2024)

Project Overview
An interactive Excel dashboard designed to analyze Q1 2024 sales data for a tech company. The goal was to provide key business insights and actionable recommendations to management.

Tools & Skills Used
- Microsoft Excel: Advanced formulas (SUMIFS, XLOOKUP), PivotTables, Pivot Charts, Slicers, Data Cleaning.
- Data Analysis: KPI creation, trend analysis, and business insights.

Key Features
- KPIs: Total Sales, Total Orders, Average Order Value.
- Interactive Charts: Sales by Region, Category, Sales Rep, Product, Monthly Trend, and Top 5 Customers.
- Dynamic Filtering: Slicers for Region, Category, Sales Rep, and Month.
- Business Insights: A dedicated section with key findings and recommendations.
